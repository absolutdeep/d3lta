## Why this matters

Three packaging problems will bite in production and in collaboration:

1. **`zod` is in `devDependencies` but is imported by `lib/theme-service.ts`,
   which is bundled into client components** (`components/theme/theme-dropzone.tsx`
   imports `importThemeFromUrl`/`importThemeFromJsonFile` from
   `@/lib/theme-service`). In a production install (`pnpm install --prod` or a
   deployment that prunes devDependencies), `zod` would be missing and the
   theme import feature would crash at runtime.
2. **`d3lta.db` (the SQLite database) and `graphify-out/` (a generated analysis
   artifact) are committed to the repo.** The DB is a local runtime artifact
   that will churn on every run; `graphify-out/` is generated output. Both
   should be gitignored and removed from tracking.
3. **Unused dependencies** (`axios`, `@dnd-kit/sortable`, `@dnd-kit/utilities`)
   and a misplaced one (`shadcn` is a CLI, belongs in devDependencies) bloat
   the install and confuse maintainers.

## Steps

### Step 1: Move `zod` from devDependencies to dependencies

```bash
pnpm add zod
pnpm remove -D zod
```

**Verify**: `grep -n '"zod"' package.json` shows `zod` under `dependencies`
(not `devDependencies`).

### Step 2: Remove unused dependencies

```bash
pnpm remove axios @dnd-kit/sortable @dnd-kit/utilities
```

**Verify**: `grep -nE '"(axios|@dnd-kit/sortable|@dnd-kit/utilities)"' package.json`
returns no matches.

### Step 3: Move `shadcn` to devDependencies

```bash
pnpm add -D shadcn
pnpm remove shadcn
```

**Verify**: `grep -n '"shadcn"' package.json` shows `shadcn` under
`devDependencies` (not `dependencies`).

### Step 4: Gitignore the DB and generated artifacts

Append to `.gitignore`:

```
# local database
*.db
*.db-journal

# generated analysis output
graphify-out/
```

**Verify**: `grep -nE '(\*.db|graphify-out)' .gitignore` shows the new lines.

### Step 5: Untrack the committed artifacts

```bash
git rm --cached d3lta.db
git rm -r --cached graphify-out
```

This removes them from the index but keeps the files on disk (they're now
ignored). Do NOT use `git rm` without `--cached` — that would delete the local
files.

**Verify**: `git status --short` shows `d3lta.db` and `graphify-out/` as
deleted-from-index (staged `D`), and `git check-ignore d3lta.db graphify-out`
prints both paths (confirming they're now ignored).

### Step 6: Verify nothing broke

```bash
pnpm run lint
npx tsc --noEmit
pnpm run build
```

**Verify**: all three exit 0. The build confirms no removed dependency was
actually imported at runtime.
